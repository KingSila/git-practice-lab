# Contributing

This is a learning project, so small, focused changes are encouraged.

1. Create a GitHub issue describing the change or bug.
2. Make a branch from `main`, using a name such as `feature/task-search` or `fix/task-count`.
3. Keep commits focused. Suggested prefixes are `feat:`, `fix:`, `docs:`, `style:`, and `chore:`.
4. Push the branch and open a pull request that links the issue and explains the change.
5. Review the diff, check the app in a browser, and merge the pull request.

For conflict practice, use a disposable branch and intentionally change the same line in two branches. Resolve the conflict, inspect the result, and commit the merge.
